# Common native exchange engine audit

FDP_PRIOR and FDP_NATIVE use the same calibration runner and native realization path. The signal changes from frozen q to frozen phi_palu; rank quantum, donor/receiver legality, factor realization, byte accounting, J objective, bootstrap acceptance, and proposal bound remain shared.

Transfer counts are calibration-derived and frozen before formal quality; no formal-test tuning was performed. The random calibration schedules are retained as a separate ablation design and are not merged into the four-method main claim.
